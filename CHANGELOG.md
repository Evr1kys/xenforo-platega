# История изменений

## 1.1.0 — 2026-09-19

- Добавлен отдельный модуль для XenForo 1.5: разовые повышения в RUB, проверка уведомлений через API, возвраты и ручное восстановление через CLI.
- Добавлены XML-установщик, выбор RUB в панели и кнопка Platega на странице повышений.
- Проверены параллельные уведомления и откат выдачи при конфликте транзакции.
- Основной пакет проверен на XenForo 2.2.13, 2.2.15, 2.2.17, 2.2.19 и 2.3.6.
- Диагностика определяет поколение XenForo и подходящий пакет.
- Сборка выпускает два архива с отдельными контрольными суммами.
- В лицензии указаны автор Evrik (Evr1kys) и профиль GitHub.

Пакет для 1.5 проверен на 1.5.24. Поддержка 1.0–1.4, 2.0 и 2.1 пока не заявлена. Новые поколения требуют проверки после выпуска.

## 1.0.0 — 2026-09-19

- Первый выпуск без отметки beta на основе Beta 3.
- Автоматическая публикация поддерживает обычные и предварительные релизы.
- Обновление с Beta 3 сохраняет настройки и историю платежей; платёжная логика не изменена.

Проверки выполняются на XenForo 2.2.19 и 2.3.6 с тестовыми ответами API. Сквозная проверка через магазин Platega перед выпуском не выполнялась.

## 1.0.0 Beta 3 — 2026-09-18

- Добавлены фильтры платежей по локальному статусу и платёжному профилю.
- Добавлена сводка количества операций по статусам, название профиля и время последнего обновления.
- Добавлены индексы таблицы по дате, статусу и платёжному профилю для быстрой работы списка на большой истории.
- Клик по ключу покупки теперь заполняет форму ручной проверки без выполнения операции через GET-запрос.
- В метаданные платежа добавлен корректный IP-адрес покупателя для антифрод-проверки; передаваемые данные явно описаны в интерфейсе и README.
- Merchant ID сохраняется в каноническом нижнем регистре, длина Secret key ограничена 512 символами.
- Ответ создания платежа централизованно проверяется: UUID транзакции, статус `PENDING` при его наличии и HTTPS-адрес перенаправления.
- Удалено недокументированное поле `orderId`; привязка к покупке продолжает выполняться через `payload`.
- Расширены протокольные тесты до 63 проверок, интеграционные — до 57 на каждом из XenForo 2.2.19 и 2.3.6.
- Усилена проверка структуры пакета: обязательные файлы, уникальность XML-идентификаторов, версии данных, ссылки на фразы и гигиена PHP-файлов.
- Добавлена проверка готового ZIP: безопасные пути, отсутствие симлинков, полнота `hashes.json`, SHA-256 и воспроизводимость сборки.
- Добавлена автоматическая публикация готового ZIP и контрольной суммы в GitHub Releases при изменении версии в основной ветке.

Обновление устанавливается поверх Beta 2, сохраняет все данные и добавляет только служебные индексы таблицы платежей.

## 1.0.0 Beta 2 — 2026-09-15

- Страница платежей в админке: список с пагинацией и поиск по идентификатору.
- Ручная обработка платежа, если уведомление не дошло до форума.
- Восстановление транзакции после таймаута по ID из кабинета Platega.
- Проверка подключения с ключами сохранённого профиля без создания оплаты.
- Отметка ручной проверки в журнале платежей.
- Проверки прав администратора, повторной обработки, возвратов и ошибок API.

Обновление устанавливается поверх Beta 1 и сохраняет платёжные профили и историю операций.

## 1.0.0 Beta 1 — 2026-09-15

Первый выпуск.

- Платёжные профили Platega для XenForo 2.2 и 2.3.
- Выбор способа оплаты на странице Platega или фиксированный способ в профиле.
- Разовые платежи в RUB и обработка возвратов.
- Проверка уведомлений по ключам и через API состояния транзакции.
- Защита от повторной выдачи покупки и повторного создания платежа после таймаута.
- Настройки и сообщения на русском языке.
- Установочный ZIP, проверки PHP и интеграционные тесты с XenForo.

Статус beta: перед использованием на рабочем форуме нужна контрольная оплата с вашим магазином Platega.
