# История изменений

## 1.0.0 Beta 2 — 2026-09-15

- Страница платежей в админке: список с пагинацией и поиск по идентификатору.
- Ручная обработка платежа, если уведомление не дошло до форума.
- Восстановление транзакции после таймаута по ID из кабинета Platega.
- Проверка подключения с ключами сохранённого профиля без создания оплаты.
- Отметка ручной проверки в журнале платежей.
- Проверки прав администратора, повторной обработки, возвратов и ошибок API.

Обновление устанавливается поверх Beta 1 и сохраняет платёжные профили и историю операций.

## 1.0.0 Beta 1 — 2026-09-15

Первый выпуск.

- Платёжные профили Platega для XenForo 2.2 и 2.3.
- Выбор способа оплаты на странице Platega или фиксированный способ в профиле.
- Разовые платежи в RUB и обработка возвратов.
- Проверка уведомлений по ключам и через API состояния транзакции.
- Защита от повторной выдачи покупки и повторного создания платежа после таймаута.
- Настройки и сообщения на русском языке.
- Установочный ZIP, проверки PHP и интеграционные тесты с XenForo.

Статус beta: перед использованием на рабочем форуме нужна контрольная оплата с вашим магазином Platega.
