# Безопасность

Если ошибка позволяет подделать оплату, получить чужой доступ или раскрыть ключи, не публикуйте рабочий пример с секретами в открытом issue. Используйте [Private vulnerability reporting](https://github.com/Evr1kys/xenforo-platega/security/advisories/new).

В обычных отчётах удаляйте Merchant ID, Secret key, данные пользователей, содержимое базы и заголовки запросов. Для диагностики обычно достаточно версий PHP/XenForo, HTTP-кода и обезличенного сообщения об ошибке.

Поддерживается последний опубликованный выпуск. В первой beta реальные платежи не проверялись с ключами магазина; перед рабочим использованием проведите контрольную оплату.
