# Совместимость с версиями XenForo

Наличие версии в диапазоне установки не означает, что на ней выполнена контрольная оплата. Ниже отдельно указаны проверенные окружения и направления расширения поддержки.

| Ветка | Состояние |
| --- | --- |
| 1.x | Нужна отдельная реализация. Текущий ZIP не подходит. |
| 2.0.x | Нужны исходники для проверки API и интеграционные тесты. Установка пока закрыта. |
| 2.1.x | Нужны исходники для проверки API и интеграционные тесты. Установка пока закрыта. |
| 2.2.x | Интеграционные тесты пройдены на 2.2.19. Ранние выпуски требуют отдельной проверки. |
| 2.3.x | Интеграционные тесты пройдены на 2.3.6. |
| Более новые | Требуется проверка после появления соответствующего выпуска. |

Сквозная оплата через API магазина Platega не проверялась. Интеграционные проверки используют тестовые ответы шлюза.

## Что отличается в старых версиях

Стандартные платёжные профили появились в ветке 2.x. Для 1.x потребуется другая интеграция с повышениями пользователей.

В [XenForo 2.2.6 добавлена проверка существования оплачиваемого товара](https://xenforo.com/community/threads/unhandled-error-when-user-upgrade-no-longer-exists.195057/). Текущая ручная обработка платежей использует этот интерфейс. Простое снижение минимальной версии дополнения не заменяет адаптацию отсутствующих методов.

## Проверка доступного дистрибутива

Запустите на версии PHP, подходящей для проверяемого движка:

```sh
php scripts/check-xenforo.php /path/to/xenforo
```

Команда читает определения классов движка, сообщает версию и отсутствующие методы. Она не устанавливает дополнение и не подключается к базе. Используйте доверенный дистрибутив: PHP-файлы движка загружаются для проверки классов.

Успех этой проверки не подтверждает работу платежей. Далее нужны отдельная тестовая база, установка дополнения и сценарии из [TESTING.md](TESTING.md): выдача покупки, возврат, повторные уведомления, ручное восстановление и обновление дополнения.

Для проверки всей ветки нужны как минимум её первый и последний поддерживаемый выпуск, а также выпуски, в которых менялся платёжный API. Непроверенные версии не следует помечать как гарантированно совместимые.
